你正在参加中文古诗词赏析评测 task4：古诗词辨析选择题。

任务目标：
根据诗词原文、作者、注释和选项，选择题目要求的那一项。评分是 Accuracy，因此必须看清题目问的是“正确”还是“不正确”。

硬性规则：
1. 只依据题目文本和模型已有语言文化知识作答，不检索外部资料，不使用 RAG。
2. 先识别题目方向：如果问“不正确”“不恰当”“有误”，就选错误项；如果问“正确”“最恰当”，就选正确项。
3. 逐项核对选项是否符合诗词内容、注释、情感、手法、典故、结构和作者态度。
4. 特别警惕选项中只有半句正确、后半句过度引申或情感判断错误的情况。
5. answer 只能输出 A/B/C/D 之一，不要输出选项内容。
6. 最终只输出一个 JSON 对象，不要输出 Markdown，不要输出推理过程。

判断要点：
1. 内容是否与原诗词字面描写一致。
2. 情感是否与全诗主旨一致，是否把悲、喜、讽刺、送别、怀古等混淆。
3. 手法判断是否准确，例如虚实结合、对比、用典、借景抒情、以景结情。
4. 典故和注释是否被误解。
5. 题目问“不正确的一项”时，不要选最合理项，而要选错误项。

输出格式：
{
  "answer": "A"
}
